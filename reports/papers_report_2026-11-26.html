SCIS：GateMate FPGA 上的慢速控制連鎖系統
本報訊｜cs.AR 硬體架構｜作者：Vitalii Burtsev, Daniele Passaretti, Daniel Anders, Christof Pfannenmueller, Fabian Lurz, Thilo Pionteck
圖：取自論文原文（點圖看原圖）

長時間運作的科學、工業與醫療設備需要監控與保護。過去多用軟體監控，但軟體會老化，反應時間也不固定。這篇提出以 FPGA（可重新設定內部電路的晶片）為核心的輕量級連鎖系統。系統在執行時收集各項參數，依設定的優先規則判斷故障，並在微秒等級的延遲內觸發急停（kill-switch）。

【實際應用】用在設備的硬體急停保護，例如馬達過流或溫度過高時立刻切斷電源。長時間運作的量測設備也適用。

【跟你的關係】你做過無人機與 Arduino 的感測整合，這類「偵測到異常就立刻停機」的設計，可以拿來對照你的韌體保護邏輯。

DTR：低功耗脈衝神經網路加速器的模組化硬體框架
本報訊｜eess.SP 訊號處理｜作者：Daniel Windhager, Lothar Ratschbacher, Bernhard A. Moser, Michael Lunglmayr
圖：取自論文原文（點圖看原圖）

脈衝神經網路（SNN，以脈衝傳遞資訊的神經網路）耗電低，但脈衝資料的儲存格式常佔用較多位元。這篇提出差分時間表示法（DTR），所需位元比位址事件表示（AER）或定時取樣的 1 位元脈衝序列少。作者證明多條 DTR 序列可低複雜度合併，並提供可串接的硬體串流模組與 Python 組裝工具。

【實際應用】把聲音或振動感測器的事件資料壓縮後送進 FPGA 辨識。適合電池供電的邊緣裝置，例如偵測異常振動的感測節點。

【跟你的關係】你有硬體電路與嵌入式的背景，這篇的模組與 Python 組裝流程可以對照，練習把演算法拆成硬體串流元件。

【原文標題】Low-Power Spiking Neural Network Acceleration with Differential Time Representation: A Modular Hardware Framework

以側掃聲納影像估測水深的神經隱式方法
本報訊｜cs.RO 機器人｜作者：Tianxiang Lin, Sacchin Sundar, Fenghao Liu, Onur Bagoren, Katherine A. Skinner
圖：取自論文原文（點圖看原圖）

多波束測深儀裝在水面船上，離海床遠時解析度有限。側掃聲納（向兩側發射聲波、記錄海床回波的聲納）可裝在水下自駕載具（AUV）上，離海床近，解析度較高。但它的量測有模糊性，覆蓋範圍也小，現有方法效果差。這篇以神經隱式表示（用神經網路代表連續的空間函數）搭配可微分神經渲染，並納入聲納幾何的量測模型來估測水深。

【實際應用】用 AUV 搭載側掃聲納掃描港口、水庫或河床，產生水深圖。

【跟你的關係】你做過無人船實地下水測試。若之後想在船或水下載具上加聲納量測水深，這篇提供資料處理方向，但它用到深度學習，需要先補一些基礎。

【原文標題】Neural Implicit Representation for Bathymetry Estimation using Sidescan Sonar Imagery
